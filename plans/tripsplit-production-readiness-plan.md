## Recommended Approach
Use the spec’s own phasing as the rollout spine. Start at **Phase 0 truthful green baseline** even though later-phase code already exists (Rule 2). For each phase, driver is a **failing test**: write the DB/executable or browser assertion first, then change the migration/RPC/component until it passes. All migrations are forward-only under `supabase/migrations/`; regenerate `src/types/database.ts` via `supabase gen types typescript` after each DB phase and delete `as any` RPC casts. Keep `src/screens/*`/`src/lib/demo.ts`/`src/data.ts` until replacement journeys are proven, then delete (spec 3.5).

The plan is agnostic to hosting (Figma Make preview vs local) because Playwright now respects `PLAYWRIGHT_BASE_URL`. Sensitive operations (admin bootstrap, site URL, OAuth, storage bucket, backup) stay in §13 external checklist and are marked **unverified** until the service-role/CI-secret path is provided.

## Risks / Rollback
- **Parametric TS upgrade risk**: bumping to 5.9.3 may surface new errors; mitigation is `skipLibCheck:true` only hides lib declaration errors, parser error must be fixed by compatible toolchain — rollback is pin + `overrides` for `zod`/`postcss` if needed, but gate fails until resolved.
- **Migration lock/liveness**: `FOR UPDATE` + `mutation_requests` serialization may expose deadlocks under concurrency tests (settlement overpay, last-owner race). Fix with consistent lock order (trip row before members) and re-try on serialization failure; rollback is forward migration amending lock order, not history rewrite.
- **Receipt storage**: private bucket + signed URL policy is net-new; misconfig leaks receipts across trips (violates §10.4 #13). Test #13 must fail the build on leak. Rollback is disabling bucket creation and hiding receipt UI behind capability flag.
- **Shell unification**: deleting `TripDashboard`/`RealTripOverview`/`demo` branches risks breaking local demo preview. Mitigate by keeping fixtures in `tests/fixtures/` and Storybook-style mocks, not in `src/` prod branches (spec 3.5).
- **Offline/axe debt**: fixing scrollbars/contrast may regress visual snapshots. Keep visual snapshots as regression aid, not substitute for axe semantics (§10.6).
- **External config remains unverified** (§13) until secrets/hosting/observability are provisioned — plan marks those gates `unverified` rather than `complete`, and Phase 7 is blocked until they are.
