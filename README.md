# Hissaab

> Shared trip expense tracking, smart debt simplification, and easy settlements.

Built with **React 19**, **Vite**, **Tailwind CSS v4**, **TypeScript**, and **Supabase**.

## Features

- ✈️ **Trip Workspaces:** Group expenses by trip with multi-currency support.
- 💸 **Flexible Expense Splitting:** Equal, percentage, custom shares, or exact amounts.
- ⚖️ **Smart Debt Simplification:** Automatic minimization of total transactions needed to settle up.
- 🤝 **Invite Codes & Passwordless Guest Join:** Seamlessly invite travelers via unique invite codes.
- 🔒 **Row-Level Security & Audit Trails:** Real-time immutable audit logging for all changes.
- 📱 **Mobile-First Design:** Responsive desktop/mobile UI with native feel.

## Tech Stack

- **Frontend:** React 19, React Router v8, TanStack Query v5, Tailwind CSS v4, Lucide Icons
- **Forms & Validation:** React Hook Form, Zod
- **Backend & Database:** Supabase (PostgreSQL, Row-Level Security, RPC Functions)
- **Testing:** Vitest, Testing Library, Playwright

## Getting Started

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Run test suite
pnpm test

# Build for production
pnpm build
```
